# Bunny Launcher

<img width="380" src="image/app_icon/icon_browser_fullsize.svg"/>

## About

A lightweight FOSS Android launcher forked from AOSP's Launcher3, using [Murine Launcher](https://github.com/alesimula/Murine-launcher) as a base (which is in turn is based on [yuchuangu85's repo](https://github.com/yuchuangu85/Launcher3))

### Differences from Murine (goals)

- Set an icon as text-only (e.g. every icon on a page for a minimal look)
- Automatically invoke keyboard when opening the app drawer
- Fuzzy-search
- Tag apps & search by tags
- Sub-grid positioning
- Private-space apps can be added to pages & appear in search when private space is disabled
  - when launched: prompt for unlock (then launch as normal)
